# Roadmap studio

## Obiettivo principale

Aiutare a passare l'esame piu velocemente, ma anche imparare davvero Python e Programmazione 2, non solo memorizzare risposte.

## Prossimo modulo: Tutorial Python

Creare una sezione "Tutorial Python" separata dai quiz, guidata step by step:

1. Fondamenta
   - variabili, tipi, input/output, operatori
   - piccoli esercizi con esecuzione reale del codice
   - feedback immediato su errore, output e soluzione

2. Controllo del flusso
   - if/elif/else
   - cicli while e for
   - range, contatori, accumulatori
   - mini-progetti: convertitore, calcolatrice, indovina numero

3. Strutture dati
   - liste, tuple, set, dizionari
   - ordinamenti, ricerche, conteggi
   - mini-progetti: rubrica, lista spesa intelligente, analizzatore voti

4. Funzioni
   - parametri, return, scope
   - decomporre un problema in pezzi piccoli
   - mini-progetti: validatore password, generatore quiz, utility matematica

5. File ed errori
   - lettura/scrittura file
   - try/except
   - mini-progetti: diario su file, parser CSV semplice, registro spese

6. Progetti medi
   - quiz CLI con punteggio
   - todo list persistente
   - analizzatore di testo
   - mini gestionale studenti/voti

## Regole del tutorial

- Ogni lezione deve avere una consegna breve, codice da scrivere, esempio atteso e verifica automatica.
- Il sistema deve far eseguire codice in sicurezza, con timeout e blocco di operazioni rischiose.
- Quando il codice e sbagliato, deve dare una spiegazione unica, diretta e con esempio.
- Ogni progetto deve sbloccare il successivo, con una progressione visibile.
- I quiz di Programmazione 2 devono poter rimandare alla lezione collegata.
